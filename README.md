SolKnife is a non-custodial Solana toolkit that lets users reclaim locked SOL rent, check token safety, swap tokens via Jupiter, and launch and manage their own tokens. It provides a suite of tools for scanning, swapping, launching, and automating token workflows without ever exposing private keys, aiming to improve security and usability for Solana developers and traders.

**Areas:** Solana · Toolkit · Token Safety · DeFi · Non-custodial
